<p align="center"><strong>One menu for the state of your Mac.</strong></p>

CPU, memory, storage, thermals, battery, network, and the processes using them. Pick a section, or print everything.

```bash
make
./mi_temp
```

```bash
./mi_temp all
./mi_temp cpu memory storage
```

Thermal sensors sometimes need `sudo`.
